What Thinking Break does

  • Fills the wait. Agent turns run anywhere from ten seconds to several minutes. Thinking Break puts a real game in that gap instead of a spinner.
  • Never asks you to navigate. The game resumes the instant your agent goes busy — same mode, same round, same score, same ammo. No menus.
  • Gets out of the way. The moment the agent stops, the game pauses, releases the pointer, suspends audio and cancels its render loop. A paused session costs essentially nothing.
  • Stays local. Static files on GitHub Pages, progress in your browser's localStorage. No account, no backend, no telemetry.

Supported agents and editors

Claude Code

Hooks into the Claude Code agent lifecycle through ~/.claude/settings.json.

  • busyPreToolUse → .*
  • idleStop
  • idleSubagentStop
Cursor

Uses Cursor's native agent hooks via a script in ~/.cursor/hooks/.

  • busybeforeSubmitPrompt
  • idlestop
  • idlesessionEnd
Codex CLI

Three-layer detection so no invocation is missed: config hooks, a shell wrapper, and process polling.

  • busyconfig exec_before
  • idleconfig exec_after
  • pollpgrep fallback
VS Code

Runs as a native extension. The game lives in a webview panel that relays lifecycle events straight into the page.

  • hostVS Code ≥ 1.85
  • panelWebview + Simple Browser fallback

How installation works

01

Downloads the source from GitHub and compiles the extensions on your machine. Nothing is fetched from a build server.

02

Packages a .vsix and installs it into whichever editors it finds — VS Code, Cursor, or both.

03

Writes agent hooks into ~/.claude/settings.json, ~/.cursor/settings.json and/or ~/.codex/config.toml, depending on what you have installed.

04

Touches nothing in your project. All state lives under ~/.thinking-break/ and the per-agent directories above.

Prefer to run agents in a plain terminal, outside an editor? The terminal installer wires the same hooks and drives a browser window instead (macOS): 

curl -fsSL https://doringber.github.io/thinkingbreak/install-terminal.sh | bash

How the busy / idle lifecycle behaves

On busy

Your agent starts a task or calls a tool.

  • Open or focus the existing panel
  • Restore the saved session
  • Resume rendering, bots and timers
  • Show an "Agent working" status
On idle / stop

Your agent finishes or you interrupt it.

  • Pause immediately, cancel the render loop
  • Freeze bots and timers, suspend audio
  • Save the session, release pointer lock
  • Hand focus back to the editor

Rapid events are safe. Agents emit a busy signal on every tool call, so a repeated busy never restarts the game, and an idle that arrives inside a short grace window is deferred — you do not get paused in the gap between two tool calls. Only one render loop can ever exist, and only one panel.

Privacy and local storage

  • No backend. The game is static files served from GitHub Pages. Nothing you do in it is sent anywhere.
  • No analytics, no accounts, no cookies.
  • One localStorage key, thinking-break/save, holds your mode, round, score, high scores, weapon, settings and aggregate stats. It is versioned, and an unreadable or outdated save is discarded rather than crashing the game.
  • Agent state stays on your machine. The extensions write a small JSON file under ~/.claude/, ~/.cursor/ or ~/.codex/ saying only whether the agent is currently busy. Your prompts and code are never read.
  • Clear it any time by opening the game with ?debug=1 and choosing “clear save”, or by clearing site data for this origin.

How to uninstall

curl -fsSL https://doringber.github.io/thinkingbreak/uninstall.sh | bash

That script removes the hook entries it added, deletes the state directories, and uninstalls the extensions. To do it by hand:

  • Uninstall Thinking Break from your editor's Extensions view.
  • Delete the thinking-break hook entries from ~/.claude/settings.json, ~/.cursor/settings.json and the marked block in ~/.codex/config.toml.
  • Remove ~/.thinking-break/, ~/.claude/thinking-break/, ~/.cursor/thinking-break/ and ~/.codex/thinking-break/.
  • macOS terminal installer only: launchctl unload ~/Library/LaunchAgents/com.doringber.thinking-break.plist, then delete that file.
